01 Rules

What it filters out

Each cliché is paired with the rule that replaces it. The README lists all 15. The references add ten sections of visual and interaction detail.

Eight common AI design clichés and the rule that replaces each one
Cliché Rule
Purple to cyan gradient on headlines, buttons, and prices One solid accent color. At most one static gradient per page, never on text.
Ambient blurred orbs over a slate-950 page A plain background chosen for the audience, light or dark.
Glass cards with glow, cursor spotlight, and nested boxes Solid surfaces with a 1px border. One level of nesting at most.
Bento grid used as the default layout Layout follows the content hierarchy. Cards only for repeated items.
Blinking “All Systems Operational” dot on a static page Status indicators only when live data backs them.
Animated counters with invented metrics Static numbers with a time window and a source.
Testimonials from people who do not exist Real quotes with name, role, and company, or no testimonial section.
“It’s not just X. It’s Y.” copy Plain sentences with a subject, a verb, and a verifiable detail.

02 Install

Install

One command adds the skill to your agent. The skill ships as Markdown, so there is nothing to build and no runtime dependency.

  1. Run the installer

    npx skills add carllosnc/anti-slop-design

  2. Pick your agent when prompted

    OpenCode, Claude Code, Cursor, Codex, and 75+ other agents. Add -g to install across all projects:

    npx skills add carllosnc/anti-slop-design -g

  3. Or copy the folder yourself

    Drop skills/anti-slop-design/ into .agents/skills/, .opencode/skills/, or .claude/skills/. For a global install, use ~/.config/opencode/skills/.

03 Workflow

How it works

Four steps, in order. The checklist comes last and blocks delivery, so the page cannot ship with a failing rule.

  1. Read the anti-patterns first

    The visual catalog and the copy rules load before any style is written.

  2. Write the content hierarchy

    Decide what the reader must understand first, then choose the layout. Never start from a card grid.

  3. Spend the decoration budget

    One accent color, solid surfaces, one icon set or none, and motion only where it shows a state change.

  4. Run the checklist

    Contrast, layout, motion, honesty, and copy. Anything that fails gets fixed before delivery.

Hard gate

  • No invented metrics, logos, certifications, or testimonials.
  • No live status indicator without a backend behind it.
  • Body text at WCAG AA contrast.
  • One primary call to action per view.
  • Solid heading colors, no gradient or animated text.
